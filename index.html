Relatorio dos canais

Relatorio dos canais é uma ferramenta de uso pessoal que ajuda o dono de alguns canais do YouTube a gerenciar o próprio conteúdo: enviar e agendar vídeos, editar títulos e descrições e acompanhar números básicos dos canais.

A ferramenta usa a API de Dados do YouTube (YouTube Data API) apenas nos canais do próprio dono, com a autorização dele.

Esta ferramenta usa os Serviços de API do YouTube. Veja os Termos de Serviço do YouTube e a Política de Privacidade do Google.
